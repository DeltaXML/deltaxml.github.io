AI for XSLT and XPath

AI coding assistants can draft XSLT, explain a stylesheet, and fix a bug - and, like any author, they make mistakes: a function that doesn't exist, a variable that is out of scope, an XPath that is subtly wrong. The question isn't only whether an assistant can write XSLT, but how quickly its mistakes are caught. That is where the editor helps.

Problems an assistant can read

The XSLT/XPath extension reports its findings as standard Visual Studio Code problems. They name the exact symbol at issue - an unresolved variable, a function called with the wrong number of arguments, a record field that doesn't exist - so an assistant such as GitHub Copilot or Claude Code can read them, explain them and fix them, then check its own change the same way. They are kept up to date for every stylesheet open in an editor, including the ones the assistant changes while your cursor is elsewhere.

Tests as a safety net

Checking catches what is wrong in the code; XSpec tests catch what is wrong in the behavior. An assistant that can run tests - or that is asked to write them first - has a way to know its XSLT does what was intended. The debugger and print debugging give it, and you, a way to see what a stylesheet did.

An MCP server (experimental)

The extension can also run a Model Context Protocol server, so that an assistant can ask it questions directly, with the same answers the editor gives: the problems in a stylesheet or a whole folder - even for files that aren't open - the tree of imports, and where a function, template, variable or other component is declared. It is off by default, and turned on with a setting.

The details are in the user guide: AI assistants.

Common questions

Can AI write XSLT?

AI coding assistants can draft and explain XSLT. Their output needs checking: in VS Code, the XSLT/XPath extension's problems and XSpec tests show quickly whether the code is right.

Does it work with GitHub Copilot and Claude Code?

Yes. Both can read the extension's problems in VS Code, and the extension's MCP server can be used by assistants that support the Model Context Protocol.

What is the MCP server for?

It lets an assistant ask the extension about your stylesheets - their problems, their imports and where things are declared - using the same code as the editor.
